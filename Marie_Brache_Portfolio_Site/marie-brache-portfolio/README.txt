MARIE BRACHE PORTFOLIO SITE
===========================

PAGES
  index.html  Home
  works.html  Gallery of all works (filters: All / Professional art / Personal art)
  work.html   Single project view (opened from the gallery, e.g. work.html?id=guide-to-new-quizzes)
  about.html  Bio
  cv.html     CV, plus a download link to Marie_Brache_CV.pdf

UPLOADING (UCF student server)
  Upload everything INSIDE this folder (index.html, the other .html files,
  Marie_Brache_CV.pdf and the whole "assets" folder) into your web folder
  on the server, keeping the folders exactly as they are.
  The server is wiped every semester, so keep this zip as your backup.

PREVIEWING ON YOUR COMPUTER
  Unzip, then double-click index.html. Everything works offline.

EDITING TITLES, YEARS AND DESCRIPTIONS
  Open assets/js/works-data.js in any text editor (Notepad, TextEdit, VS Code).
  Each work has fields such as:
      "title": "Character Study No. 1",
      "year": "",            <- type a year here, e.g. "2022", to show "Completed"
      "description": "...",
      "featured": true       <- true = shown on the home page
  Keep the quotation marks and commas, then save and re-upload that one file.
